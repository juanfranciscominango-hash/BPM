¿Qué es Redis?

Redis (Remote Dictionary Server) es un almacén de estructura de datos en memoria, utilizado como base de datos, caché y agente de mensajes. En este proyecto se utiliza principalmente como sistema de caché distribuido para mejorar el rendimiento.

Nota: Redis se integra con el sistema de autenticación MSAL para cache seguro de datos de usuario y sesiones.

Servicio de Redis
Servicio Base de Cache

Implementación del servicio Redis en src/app/services/redis.service.ts:

import { Injectable } from '@angular/core';
import { Redis } from 'redis';
import { environment } from '../../environments/environment';

@Injectable({
  providedIn: 'root'
})
export class RedisService {
  private client: Redis;

  constructor() {
    this.client = Redis.createClient({
      host: environment.redis.host,
      port: environment.redis.port,
      password: environment.redis.password
    });

    this.client.on('error', (err) => console.error('Redis Client Error', err));
  }

  async connect(): Promise<void> {
    await this.client.connect();
  }

  async set(key: string, value: any, ttl?: number): Promise<void> {
    const fullKey = environment.redis.keyPrefix + key;
    const serializedValue = JSON.stringify(value);
    if (ttl) {
      await this.client.setEx(fullKey, ttl, serializedValue);
    } else {
      await this.client.set(fullKey, serializedValue);
    }
  }

  async get<T>(key: string): Promise<T | null> {
    const fullKey = environment.redis.keyPrefix + key;
    const value = await this.client.get(fullKey);
    return value ? JSON.parse(value) : null;
  }

  async delete(key: string): Promise<number> {
    const fullKey = environment.redis.keyPrefix + key;
    return await this.client.del(fullKey);
  }

  async exists(key: string): Promise<boolean> {
    const fullKey = environment.redis.keyPrefix + key;
    const result = await this.client.exists(fullKey);
    return result === 1;
  }

  async expire(key: string, ttl: number): Promise<boolean> {
    const fullKey = environment.redis.keyPrefix + key;
    return await this.client.expire(fullKey, ttl);
  }

  async keys(pattern: string): Promise<string[]> {
    const fullPattern = environment.redis.keyPrefix + pattern;
    return await this.client.keys(fullPattern);
  }

  async disconnect(): Promise<void> {
    await this.client.disconnect();
  }
}
Ejemplos de Uso
Cache de Usuario

Cache de datos de usuario con MSAL

export class UserService {
  constructor(private redis: RedisService) {}

  async getUserData(userId: string) {
    const cacheKey = `user:${userId}`;

    // Intentar obtener de cache primero
    let userData = await this.redis.get(cacheKey);

    if (!userData) {
      // Si no está en cache, obtener de API
      userData = await this.api.getUser(userId);
      // Guardar en cache por 30 minutos
      await this.redis.set(cacheKey, userData, 1800);
    }

    return userData;
  }
}
Cache de API

Cache de respuestas de API

export class ApiCacheService {
  constructor(private redis: RedisService) {}

  async getCachedApiResponse(endpoint: string) {
    const cacheKey = `api:${endpoint}`;

    let response = await this.redis.get(cacheKey);

    if (!response) {
      response = await this.http.get(endpoint).toPromise();
      // Cache por 15 minutos
      await this.redis.set(cacheKey, response, 900);
    }

    return response;
  }

  async invalidateApiCache(endpoint: string) {
    const cacheKey = `api:${endpoint}`;
    await this.redis.delete(cacheKey);
  }
}
