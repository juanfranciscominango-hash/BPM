Documentación WCF

Guía completa para la integración con servicios WCF

¿Qué es WCF?

Windows Communication Foundation (WCF) es un framework para construir aplicaciones orientadas a servicios. Permite crear servicios web seguros y confiables que se comunican a través de diferentes protocolos.

Nota: En este proyecto, WCF se utiliza para integrar con servicios legacy existentes, manteniendo compatibilidad con sistemas antiguos.
Arquitectura WCF
Componentes Principales
  • 🔧 Service Contract: Define las operaciones del servicio
  • 📋 Data Contract: Define los tipos de datos
  • 📡 Message Contract: Control de mensajes SOAP
  • 🏗️ Endpoint: Dirección, binding y contrato
  • 🔗 Binding: Protocolo de comunicación
Bindings Comunes
  • 🌐 BasicHttpBinding: HTTP básico (legacy)
  • 🔒 WSHttpBinding: WS-* con seguridad
  • 🚀 NetTcpBinding: TCP optimizado
  • 📡 NetNamedPipeBinding: Named pipes
  • 📧 NetMsmqBinding: Message queuing

Servicio de WCF
Servicio Base WCF

Implementación del cliente WCF en src/app/services/wcf.service.ts:

import { Injectable } from '@angular/core';
import { HttpClient, HttpHeaders } from '@angular/common/http';
import { Observable, throwError } from 'rxjs';
import { catchError, map } from 'rxjs/operators';
import { environment } from '../../environments/environment';

@Injectable({
  providedIn: 'root'
})
export class WcfService {
  constructor(private http: HttpClient) {}

  callService<T>(serviceName: string, methodName: string, parameters: any = {}): Observable<T> {
    const serviceConfig = environment.wcf.services[serviceName];
    if (!serviceConfig) {
      throw new Error(`Service ${serviceName} not configured`);
    }

    const soapEnvelope = this.buildSoapEnvelope(methodName, parameters);
    const headers = new HttpHeaders({
      'Content-Type': 'text/xml; charset=utf-8',
      'SOAPAction': `"http://tempuri.org/I${serviceName}/${methodName}"`
    });

    return this.http.post(serviceConfig.endpoint, soapEnvelope, {
      headers,
      responseType: 'text'
    }).pipe(
      map(response => this.parseSoapResponse<T>(response)),
      catchError(error => this.handleSoapError(error))
    );
  }

  private buildSoapEnvelope(methodName: string, parameters: any): string {
    let paramsXml = '';
    for (const [key, value] of Object.entries(parameters)) {
      paramsXml += `<${key}>${this.escapeXml(value as string)}</${key}>`;
    }

    return `<?xml version="1.0" encoding="utf-8"?>
<s:Envelope xmlns:s="http://schemas.xmlsoap.org/soap/envelope/">
  <s:Body>
    <${methodName} xmlns="http://tempuri.org/">
      ${paramsXml}
    </${methodName}>
  </s:Body>
</s:Envelope>`;
  }

  private parseSoapResponse<T>(soapResponse: string): T {
    try {
      // Parse XML to JSON (simplified implementation)
      const parser = new DOMParser();
      const xmlDoc = parser.parseFromString(soapResponse, 'text/xml');

      // Extract result from SOAP body
      const resultNode = xmlDoc.getElementsByTagName('result')[0] ||
                        xmlDoc.getElementsByTagName('*')[0];

      if (resultNode) {
        return JSON.parse(resultNode.textContent || '{}');
      }

      return {} as T;
    } catch (error) {
      console.error('Error parsing SOAP response:', error);
      throw new Error('Invalid SOAP response format');
    }
  }

  private handleSoapError(error: any) {
    console.error('SOAP Error:', error);

    // Extract SOAP fault information
    if (error.error && typeof error.error === 'string') {
      try {
        const parser = new DOMParser();
        const xmlDoc = parser.parseFromString(error.error, 'text/xml');
        const faultNode = xmlDoc.getElementsByTagName('Fault')[0];

        if (faultNode) {
          const faultString = faultNode.getElementsByTagName('faultstring')[0];
          if (faultString) {
            return throwError(() => new Error(faultString.textContent || 'SOAP Fault'));
          }
        }
      } catch (parseError) {
        // Ignore parsing errors
      }
    }

    return throwError(() => error);
  }

  private escapeXml(unsafe: string): string {
    return unsafe.replace(/[<>&'"]/g, (c) => {
      switch (c) {
        case '<': return '<';
        case '>': return '>';
        case '&': return '&';
        case '\'': return ''';
        case '"': return '"';
        default: return c;
      }
    });
  }
}
Ejemplos de Uso
Servicio de Usuarios

Integración con servicio WCF de usuarios

export class UserWcfService {
  constructor(private wcf: WcfService) {}

  getUser(userId: number): Observable<User> {
    return this.wcf.callService<User>(
      'userService',
      'GetUser',
      { userId }
    );
  }

  createUser(user: User): Observable<number> {
    return this.wcf.callService<number>(
      'userService',
      'CreateUser',
      {
        firstName: user.firstName,
        lastName: user.lastName,
        email: user.email
      }
    );
  }

  updateUser(user: User): Observable<boolean> {
    return this.wcf.callService<boolean>(
      'userService',
      'UpdateUser',
      {
        userId: user.id,
        userData: JSON.stringify(user)
      }
    );
  }
}
Servicio de Datos

Operaciones CRUD con servicio WCF

export class DataWcfService {
  constructor(private wcf: WcfService) {}

  getData(tableName: string, filters: any): Observable<any[]> {
    return this.wcf.callService<any[]>(
      'dataService',
      'GetData',
      {
        tableName,
        filterJson: JSON.stringify(filters)
      }
    );
  }

  saveData(tableName: string, data: any[]): Observable<boolean> {
    return this.wcf.callService<boolean>(
      'dataService',
      'SaveData',
      {
        tableName,
        dataJson: JSON.stringify(data)
      }
    );
  }

  executeQuery(query: string): Observable<any> {
    return this.wcf.callService<any>(
      'dataService',
      'ExecuteQuery',
      { query }
    );
  }
}
Manejo de Errores SOAP
Tipos de Errores Comunes
  • 🚫 SOAP Fault: Errores del servicio WCF
  • ⏱️ Timeout: Servicio no responde
  • 🔒 Security: Problemas de autenticación
  • 📡 Network: Problemas de conectividad
  • 📄 Format: Mensaje SOAP mal formado
Estrategias de Manejo
// Manejo de errores robusto
callWcfService() {
  return this.wcf.callService('service', 'method')
    .pipe(
      catchError(error => {
        if (error.message.includes('SOAP Fault')) {
          // Manejar errores del servicio
          return this.handleSoapFault(error);
        }
        if (error.name === 'TimeoutError') {
          // Reintentar operación
          return this.retryOperation();
        }
        // Error genérico
        return throwError(() => new Error('Service unavailable'));
      })
    );
}

Solución de Problemas

FaultException

Solución: Revisar parámetros y lógica del servicio. Verificar contratos de datos.

CommunicationException

Solución: Verificar conectividad de red y configuración de endpoints.

Timeout en operaciones largas

Solución: Aumentar timeouts en configuración y optimizar consultas.

receiveTimeout: 300000

Solución: Verificar certificados y configuración de seguridad.
